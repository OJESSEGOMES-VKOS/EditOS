# cena27 Day counter: componente

**Props:** `rotulo`, `palavra` (a unidade dita, ex. "DIA"), `mes`, `dias` (quadrinhos do calendário), `ate` (dia em que o contador pousa; padrão `dias`; até 8 vira só batidas), `fimQuadro` (quadro do pouso, padrão 79; o ritmo inteiro escala), `inicioSemana` (coluna do dia 1, 0 = domingo; use o mês real), `iniciaisSemana`, `vermelho`, `width`, `height`. Os textos da demo estão em `textos-demo.json`: nenhum deles vai para um vídeo novo. Como compor uma cena nova: `../cena27.md` (A personalidade, Como variar).
