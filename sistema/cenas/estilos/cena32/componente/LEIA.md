# cena32 — Nota fiscal: componente

Props: `loja`, `data`, `itens` (4, máx. 5: `nome`, `valor`), `total`.

O que tem: Impressora em caixa CSS 3D com tampo de vidro, fenda e barra de corte; o papel é uma fileira de tiras de 24 px com curva crescente para trás (cada tira mostra sua fatia do conteúdo), mais escuro perto da fenda; cada linha só aparece saindo da fenda em passos rápidos com um balanço no fim; câmera faz arco e recua.
