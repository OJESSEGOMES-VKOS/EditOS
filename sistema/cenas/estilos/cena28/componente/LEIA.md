# cena28 Versus: componente

**Props:** `nomeA`, `nomeB`, `subtitulo`, `linhas[] {rotulo, a, b, vence}` (1 a 4; a última é o desfecho; número ou texto como Sim/Não), `inicios[]` (quadro de cada linha, padrão 8 + i×13), `formato` (padrão número com milhar; a demo passa `R$`), `azul`, `laranja`, `width`, `height`. A placa e o acender do desfecho tomam a cor de quem vence. Números da demo ilustrativos. Os textos da demo estão em `textos-demo.json`: nenhum deles vai para um vídeo novo. Como compor uma cena nova: `../cena28.md` (A personalidade, Como variar).
